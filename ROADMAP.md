# Roadmap

This document outlines the development plan and future vision for **CoffeShop**.

## 📍 Short-Term Goals (Q1 2024)

-   [ ] **User Profiles**: Enhanced profile management with avatar uploads.
-   [ ] **Favorites**: Ability to save favorite items for quick re-ordering.
-   [ ] **Dark Mode**: Full system-wide dark mode support.
-   [ ] **Payment Integration**: Stripe or PayPal integration for real payments.

## 🔭 Mid-Term Goals (Q2 2024)

-   [ ] **Loyalty Program**: Points system for frequent buyers.
-   [ ] **Push Notifications**: Order status updates via Expo Notifications.
-   [ ] **Admin Dashboard**: Web portal for shop owners to manage inventory.
-   [ ] **Multi-language Support**: i18n implementation.

## 🚀 Long-Term Vision

-   **AI Recommendations**: Personalized coffee suggestions based on purchase history.
-   **Subscription Model**: Monthly coffee subscription service.
-   **Franchise Support**: Multi-tenant architecture for multiple coffee shop locations.

## 📝 Disclaimer

This roadmap is subject to change based on user feedback and development priorities.
