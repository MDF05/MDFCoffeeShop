# Governance Model

This document outlines the governance structure for the **CoffeShop** project.

## 👑 Project Roles

### Project Lead / Owner
**mdavafahreza** is the benevolent dictator of this project.

**Responsibilities:**
-   Sets the overall direction and strategy.
-   Has final say on all technical and design decisions.
-   Manages releases and publication to app stores.
-   Ensures the community adheres to the Code of Conduct.

### Contributors
Contributors are community members who:
-   Submit pull requests.
-   Report issues and bugs.
-   Improve documentation.

## 🤝 Decision Making Process

1.  **Consensus Seeking**: We aim for consensus among contributors for most changes.
2.  **Final Say**: If consensus cannot be reached, the Project Lead has the final decision.
3.  **Transparency**: Major decisions will be discussed openly in GitHub Issues or Discussions.

## 📝 Contribution Process

1.  **Discussion**: Open an issue to discuss major changes before implementing them.
2.  **Implementation**: Fork the repo and create a Pull Request.
3.  **Review**: A maintainer will review the code.
4.  **Merge**: Once approved, the code will be merged into the `develop` branch.
